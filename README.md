# Lucas Freitas

Estudante de Ciência da Computação na UFC. Construo produtos de software com LLMs em produção: agentes que usam ferramentas, RAG e extração estruturada, sobre backends em Python e TypeScript.

### O que eu construo

- **[ZapMark](https://zapmark.howluks.dev)**: SaaS de agendamento pelo WhatsApp com atendente LLM (Gemini ou Claude). O agente usa 11 ferramentas para consultar a agenda, agendar e remarcar, tem memória por RAG com pgvector e passa por 77 testes automatizados com deploy contínuo. *Código privado (produto pago).*
- **[equipe-agentes-claude-code](https://github.com/HowLuks/equipe-agentes-claude-code)**: 8 subagentes do Claude Code com permissões por função e uma memória compartilhada de aprendizados, que uso em todos os meus projetos. [Artigo](https://github.com/HowLuks/equipe-agentes-claude-code/blob/main/docs/artigo.md).
- **[ProspectorClaude](https://github.com/HowLuks/ProspectorClaude)**: pipeline de agentes para prospecção B2B com a API do Claude, servidor MCP e Playwright.
- Automações com IA para a agência onde sou responsável técnico: agente de agenda por WhatsApp com saída estruturada do Gemini, prospecção no Google Maps e CRM próprio. *Código privado.*
